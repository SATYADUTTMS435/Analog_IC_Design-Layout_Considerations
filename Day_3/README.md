This document describes the work completed on **Day 3** of the *Analog IC Design and Layout Considerations* workshop.  
The focus of this session was understanding **CTAT and PTAT voltage generation** and designing a **Bandgap Reference (BGR)** using **PNP transistors, resistors, and an operational amplifier**.

---

## Objective

- To understand **CTAT (Complementary To Absolute Temperature)** behavior
- To understand **PTAT (Proportional To Absolute Temperature)** behavior
- To design a **Bandgap Reference (BGR)** circuit
- To generate a **temperature-independent reference voltage**
- To analyze the mathematical basis of BGR operation

---

##  Temperature Dependence of Semiconductor Parameters

### CTAT Quantity
- Base–Emitter Voltage (**VBE**) of a BJT
- Decreases with increase in temperature
- Hence, **VBE is CTAT**

### PTAT Quantity
- Difference in base–emitter voltages (**ΔVBE**) between two BJTs
- Increases linearly with temperature
- Hence, **ΔVBE is PTAT**

---

##  Bandgap Reference Circuit Description

The Bandgap Reference circuit consists of:
- Two **PNP transistors** operating at different current densities
- A set of **resistors** to scale currents and voltages
- An **operational amplifier** to enforce equal node voltages
- A reference output node producing **VREF**

The op-amp forces equal voltages at its inputs, ensuring precise current ratios and voltage generation.

---

##  CTAT Voltage Generation

For a PNP transistor, the base–emitter voltage is given by: **VBE = VT * ln(IC / IS)**


Where:
- VT = kT / q (thermal voltage)
- IC = collector current
- IS = saturation current

As temperature increases:
- VT increases slightly
- IS increases exponentially
- Overall, **VBE decreases with temperature**

Thus: VBE → CTAT


---

##  PTAT Voltage Generation

When two PNP transistors operate at different current densities: **ΔVBE = VBE1 − VBE2**

This simplifies to: **ΔVBE = VT * ln(n)**

Where:
- n = emitter area ratio or current density ratio

Since: **VT = kT / q**

We get: **ΔVBE ∝ T**


Thus: **ΔVBE → PTAT**


---

##  PTAT Current Generation

The PTAT voltage is converted into a current using a resistor: **IPTAT = ΔVBE / R**

The resistor is designed such that: **IPTAT = ______ µA**

---

##  Reference Voltage (VREF) Generation

The reference voltage is generated by summing a CTAT voltage and a scaled PTAT voltage: **VREF = c1 * VBE + c2 * ΔVBE**

Where:
- c1 and c2 are scaling constants set by resistor ratios

---

##  Alternative Expression for VREF

Using resistor scaling, the output reference voltage can be written as: **VREF = VBE2 + VT * ln(n) * (1 + R2 / R3)**

Where:
- VBE2 = base–emitter voltage of the output transistor
- VT = thermal voltage at operating temperature
- n = emitter area ratio
- R2, R3 = resistor values
